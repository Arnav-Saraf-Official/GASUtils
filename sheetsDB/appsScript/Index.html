SheetsDB

The web app is running.

This is a JSON API backed by Google Sheets — point your HTTP client at this URL. The UI in the demoSite/ folder of the repo is the reference client.

Quick test

curl -X POST "<this URL>?table=_tables" \
  -H "Content-Type: text/plain" \
  -H "Authorization: Bearer <your-key>" \
  -d '{"_method":"GET"}'

See docs.md in the repo for the full API reference.
